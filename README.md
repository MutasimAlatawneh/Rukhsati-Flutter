# Jodrive (Rukhsati) — Flutter Driving Test Booking App

Jodrive is a Flutter mobile app for **booking driving tests**. It supports two roles:

- **Users** can sign up/sign in, browse available slots by test center and exam type, submit bookings, view appointment status, and see reminders for upcoming approved exams.
- **Center admins** can manage availability (time slots/seats) and approve or reject pending bookings.

The backend is powered by **Firebase Authentication** and **Cloud Firestore**.

## Tech stack

- **Flutter / Dart**
- **Firebase**
  - `firebase_core` (initialization)
  - `firebase_auth` (email/password authentication)
  - `cloud_firestore` (app data: users, bookings, centers, time slots, settings)
- **UI & utilities**
  - Material UI
  - `intl` (date formatting)
- **Other dependencies (present in `pubspec.yaml`)**
  - `provider` (declared; current code primarily uses local `setState` + a `SafeState` mixin)
  - `csv`, `excel`, `pdf`, `path_provider`, `open_file`, `url_launcher`

## App structure (high level)

- **Entry point**: `lib/main.dart`
  - Initializes Firebase via `DefaultFirebaseOptions.currentPlatform`
  - Uses named routes:
    - `/auth`
    - `/user-dashboard`
    - `/admin-dashboard`
- **Auth + role routing**: `lib/pages/auth_page.dart`
  - Reads the signed-in user document from Firestore (`users/{uid}`) and routes by `role`
- **User pages**: `lib/pages/userRole/`
  - Booking, appointments, reminders, guidelines, profile
- **Admin pages**: `lib/pages/adminRole/`
  - Availability management, booking approvals, settings, profile

## Firebase / data model notes

This app expects Firebase to be configured (FlutterFire) and Firestore collections similar to:

- `users` (with fields like `role` and (for admins) `center`)
- `bookings`
- `centers/{centerId}/time_slots`
- `exam_types`
- `test_centers`
- `settings/global`

Your exact schema and security rules should match the app logic and your `firestore.rules`.

## Run locally

### Prerequisites

- Flutter SDK installed (`flutter --version`)
- A configured device or emulator:
  - Android Studio emulator, iOS simulator (macOS), or a physical device
- Firebase configured for this Flutter project

### 1) Install dependencies

```bash
flutter pub get
```

### 2) Firebase setup (required)

This project uses FlutterFire configuration (`lib/firebase_options.dart`) and platform-specific Firebase files.

Make sure you have:
- `lib/firebase_options.dart` present (usually generated by FlutterFire)
- Android `google-services.json` in `android/app/`
- iOS `GoogleService-Info.plist` in `ios/Runner/` (if running on iOS)

If you need to (re)generate config with FlutterFire CLI:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

### 3) Run the app

```bash
flutter run
```

### Useful commands

```bash
flutter devices
flutter run -d <device_id>
flutter clean
flutter pub get
```

## Troubleshooting

- **Firebase init errors**: confirm Firebase files exist and your project is correctly configured for the current platform.
- **Firestore permission errors**: verify your `firestore.rules` and that authenticated users have access to the required collections.
- **Assets not found**: ensure `assets/logoo.png` exists and matches `pubspec.yaml`.
